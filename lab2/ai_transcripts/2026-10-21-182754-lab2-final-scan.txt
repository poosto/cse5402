  The Clippy warning

  Clippy is Rust's optional lint tool. It is not part of the compiler, so it
  doesn't count against the "no warnings" rule. In SceneFragment::recite you
  have if line > expected_line { … } else if line < expected_line { … }. The
  comparison_chain lint suggests writing that as:

  match line.cmp(&expected_line) {
      cmp::Ordering::Greater => { /* missing lines */ }
      cmp::Ordering::Less => { /* duplicate */ }
      cmp::Ordering::Equal => {}
  }

  It's purely a style suggestion. Newer Clippy versions have even taken it out
  of the default set, which is why it didn't show up when I ran Clippy 1.88. You
  can skip it or change it, whichever you prefer.
